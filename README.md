# CHIBI GANG WAR — bản thử nghiệm iOS

Bản prototype offline gồm:
- Màn hình mở game tông đen/đỏ.
- Nền gradient được random khi bấm VÀO GAME.
- Thành phố 3D đơn giản bằng SceneKit.
- Nhân vật thử nghiệm, joystick cảm ứng, camera theo sau.
- Nút ĐÁNH tạo hoạt ảnh (chưa có sát thương hoặc đối thủ).

Chưa có tài khoản thật, máy chủ, multiplayer, chat, băng nhóm, chiến tranh lãnh thổ,
shop, tiền tệ, nhiệm vụ, lưu dữ liệu, vũ khí thật, AI hoặc chống gian lận.

Build bằng XcodeGen: `xcodegen generate`, mở project trong Xcode.
Bundle ID: `com.chibigangwar.vn`.
